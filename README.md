# typing-activity-tracker

キーボードごとの打鍵の「速度」と「正確さ」を計測する、Windows常駐型のタスクトレイアプリです。
USB/Bluetoothキーボードの抜き差しを検知して、使っているキーボードを自動的に判別する機能もあります。

## 使う前に(重要)

- **業務PC・会社支給端末で使う場合は、必ず情報システム部門の許可を得てから使ってください。**
  このアプリはWindowsのグローバルキーフックを使う常駐アプリのため、無許可でインストールすると
  セキュリティインシデントとして扱われる可能性があります。
- **同一モデルのキーボードを複数台お持ちの場合、USB自動検出では区別できません。** キーボードの
  識別にはUSB/BluetoothのベンダーID・プロダクトID(VID/PID)を使っていますが、同じ製品(同じ
  型番)であれば当然同じIDになるため、システム側には区別する手段がありません。この場合は
  タスクトレイ or ダッシュボードから手動で切り替えてください。
- **2台のキーボードを同時に使い分けることには対応していません。** どちらを使っているかは判別
  できないため、最後に挿さった方が「現在使用中」として扱われます(詳細は[SPEC.md](SPEC.md)の
  シナリオ3を参照)。1台ずつ使う運用を前提にしています。

## プライバシーについて

このアプリは**実際に入力した文字列(何を打ったか)は一切記録しません。**
記録するのは以下の情報のみです。

- キーの種別(通常の文字キー / Backspace / Delete のいずれか)
- 押下したタイムスタンプ
- そのとき選択されていたキーボードのラベル(自分で名前を付けたもの)
- (USB自動検出を使う場合)接続されたキーボードのVID/PID、キーボードラベルの切替履歴

グローバルキーフックを使う仕組み上、Windows Defenderやウイルス対策ソフトから
「キーロガー」として警告・誤検知される場合があります。ソースコードは
すべて公開しているので、上記の記録内容が実装と一致していることを確認できます
(`app/capture.py` 参照)。「実際の文字を記録しない」ことは`tests/test_capture.py`の
単体テストでも保証しています。

## 計測方法

- **速度**: 打鍵の間隔が一定時間(デフォルト2秒)以上空いたら「バースト」の区切りとし、
  バーストごとに CPM(1分あたりの文字数)を算出。日次サマリではバーストCPMの中央値を採用します。
- **正確さ**: Backspace/Deleteが直前の打鍵から短時間(デフォルト1秒)以内なら「タイポ訂正」、
  それより間隔が空いていれば「言い回しの推敲」とみなして区別します。
  訂正率 = タイポ訂正回数 ÷ 総打鍵数。
- ダッシュボードでは日次に加えて、週次/月次/年次のサマリも切り替えて見られます。

詳細な仕様は [SPEC.md](SPEC.md) を参照してください。

## セットアップ

このreadmeがあるフォルダで以下を実行
```
pip install -r requirements.txt
python -m app.main
```

初回起動時はブラウザで初期設定画面が開きます。外部キーボードを使う場合は名前を付けて登録、
ノートPC内蔵キーボードのみで使う場合は「外部接続キーボードを使わない」にチェックしてください。

起動するとタスクトレイにアイコンが常駐します。選択中のキーボードラベルに応じてアイコン画像
(タスクトレイ・ブラウザタブのfaviconの両方)が切り替わります(`app/icons.py`の
`KEYBOARD_ICON_FILES`に対応表がある「職場aula65%」「自宅TH40%」のみ専用アイコン、それ以外は
デフォルトアイコン)。アイコン画像は`app/assets/icons/generate_icons.py`で生成しており、
`app/assets/icons/piskel/`配下の`.piskel`ファイルをPiskelエディタで編集できます。

- 「キーボードを切替」: 登録済みのキーボードラベルに手動で切り替える
- 「ダッシュボードを開く」: ブラウザでローカルダッシュボード(`http://127.0.0.1:5151/`)を開く
- 「終了」: 常駐を終了

新しいキーボードラベルの**追加**はタスクトレイではなく、ダッシュボード画面上のフォームから行います
(バックグラウンドスレッドからtkinterの入力ダイアログを開くと、Windowsがそのウィンドウに
キー入力フォーカスを渡さず文字が打てないことがあったため、常にアクティブなブラウザ側に寄せています)。

### USB自動検出について

登録済みのキーボードを挿すと自動的にそのラベルに切り替わり、Windowsのトースト通知で知らせます。
未登録のキーボードを挿した場合は通知が出て、クリックするとブラウザで登録画面が開きます
(登録済みラベルに紐付けるか、新規登録するか選べます)。

抜いた場合はすぐにdefaultへは切り替わらず、5秒の猶予期間を置きます(スリープ復帰時のUSB瞬断等で
誤って切り替わらないようにするため)。猶予期間中に挿し直せば何も起きません。

**BluetoothキーボードはVID/PIDが取得できず自動検出の対象外になることがあります**(実機未検証)。
その場合は手動切替をお使いください。

## 設定

`config.json` をプロジェクト直下に置くと、以下の値を上書きできます(未設定時はデフォルト値)。

```json
{
  "burst_gap_seconds": 2.0,
  "typo_window_seconds": 1.0,
  "db_path": "data/events.db",
  "dashboard_host": "127.0.0.1",
  "dashboard_port": 5151,
  "device_grace_period_seconds": 5.0
}
```

## 配布用ビルド

PyInstallerで単一の.exeにビルドし、GitHub Releasesで公開しています。コード署名はしていません
(個人配布のためコストが見合わないと判断し、ソースコード公開による透明性で代替しています)。

```
pip install pyinstaller
pyinstaller --onefile --windowed --name typing-activity-tracker --add-data "app/templates;app/templates" --add-data "app/assets;app/assets" run.py
```

`app/main.py`を直接ビルド対象にすると、PyInstallerがそれをトップレベルスクリプト扱いして
`app`パッケージの相対importが壊れるため、`app.main`を絶対importする`run.py`をビルド対象にしている。

ビルドしたexeと同じフォルダに`config.json`を置けば、そのexeでの設定・打鍵データ(`data/events.db`)
の置き場所として使われる(PyInstallerのonefileビルドは実行のたびに別の一時フォルダに展開されるため、
exe自体があるフォルダを基準にしている。`app/config.py`参照)。
